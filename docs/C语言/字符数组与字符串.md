# 字符数组与字符串

## C没有字符串类型

C语言的字符串 = **以 `\0` 结尾的一段字符内存**。`\0`（ASCII 0，NUL）是唯一的"字符串结束约定"：

```mermaid
graph LR
    subgraph "内存中的 \"hello\"（6字节）"
    A[h] --- B[e] --- C[l] --- D[l] --- E[o] --- F["\\0"]
    end
```

所有字符串函数（`printf %s`、`strlen`、`strcpy`…）都**依赖这个结尾标记**才能知道字符串到哪结束。

## 三种"字符串"写法对比

```c
char s1[]  = "hello";        /* 栈：数组拷贝，内容可改 */
char *s2   = "hello";        /* s2在栈，"hello"在rodata，不可改 */
char s3[10] = "hi";          /* 栈：{'h','i',0,0,0,0,0,0,0,0} 剩余清零 */
```

| 写法 | 本体位置 | 可修改 | sizeof | strlen | 拼接/赋值 |
| --- | --- | --- | --- | --- | --- |
| `char s1[] = "hello";` | 栈（拷贝） | ✔ | 6 | 5 | 不可整体赋值 |
| `char *s2 = "hello";` | rodata | ✘（段错误） | 4/8 | 5 | 可指向别的字符串 |
| `char s3[10] = "hi";` | 栈 | ✔ | 10 | 2 | 不可整体赋值 |

```c
s1[0] = 'H';    /* ✔ "Hello" */
s2[0] = 'H';    /* 💥 SIGSEGV：写只读段 */
s1 = "world";   /* ✘ 编译错误：数组名不可赋值 */
s2 = "world";   /* ✔：改的是指针的指向 */
```

## strlen vs sizeof

```c
char s[] = "hello";
sizeof(s);      /* 6：含\0，编译期，问"这块内存多大" */
strlen(s);      /* 5：不含\0，运行期，问"\0前有几个字符" */

char t[10] = "hi";
sizeof(t);      /* 10 */
strlen(t);      /* 2 */
```

**strlen 是 O(n) 运行期扫描**：从首地址逐字节找 `\0`。

## 常用字符串函数（string.h）

| 函数 | 原型 | 要点 |
| --- | --- | --- |
| `strlen` | `size_t strlen(const char *s)` | 扫到`\0`为止，不含`\0` |
| `strcpy` | `char *strcpy(char *dst, const char *src)` | **不检查目标大小**，溢出UB |
| `strncpy` | `char *strncpy(char *dst, const char *src, size_t n)` | 拷n字节；src不足n则补`\0`；**src≥n时不补`\0`**！ |
| `strcat` | `char *strcat(char *dst, const char *src)` | 追加，同样不查大小 |
| `strncat` | `... (char*, const char*, size_t n)` | 追加最多n字符，**会补`\0`** |
| `strcmp` | `int strcmp(const char *a, const char *b)` | 逐字符比较到`\0`或分出大小；**返回值不是-1/0/1**，是差值符号 |
| `strncmp` | `int strncmp(a, b, n)` | 只比前n个 |
| `strchr` | `char *strchr(const char *s, int c)` | 找字符，返回**首次出现地址**或NULL |
| `strstr` | `char *strstr(const char *s, const char *sub)` | 找子串 |
| `strdup` | `char *strdup(const char *s)` | malloc+拷贝，**调用者负责free**（POSIX） |
| `strtok` | `char *strtok(char *s, const char *delim)` | 切分；**破坏原串**且内部有static状态（不可重入） |

使用示例：

```c
char buf[64] = "hello";

size_t len = strlen(buf);                  /* 5 */
strcat(buf, " world");                     /* "hello world"，总长11 < 64 安全 */
if (strcmp(buf, "hello world") == 0) { }   /* 相等返回0！注意==0才相等 */
char *p = strchr(buf, 'w');                /* 指向 'w' */
printf("%s\n", p);                         /* "world" */
char *sub = strstr(buf, "lo w");           /* 找子串 */
```

### strcmp 返回值的正确用法

```c
strcmp(a, b) == 0     /* 相等 */
strcmp(a, b) < 0      /* a 字典序小于 b */
strcmp(a, b) > 0      /* a 大于 b */
/* 错误习惯：if (!strcmp(a,b)) 能用但难读；if (strcmp(a,b)==1) 完全错误 */
```

### 手写 strlen：体会"扫到\0"

```c
size_t my_strlen(const char *s)
{
    const char *p = s;
    while (*p)          /* *p != '\0' */
        p++;
    return (size_t)(p - s);   /* 指针差 = 字符数 */
}
```

### 手写 strcpy：体会"\0也要拷"

```c
char *my_strcpy(char *dst, const char *src)
{
    char *ret = dst;
    while ((*dst++ = *src++))   /* 拷完'\0'后表达式为0，循环自然终止 */
        ;
    return ret;
}
```

`(*dst++ = *src++)` 一行完成"取字符-拷贝-双指针前移-判断是否为0"，是C最经典的惯用法。

## 手动构造字符串与结束符事故

```c
/* 事故1：忘留\0空间 */
char s[5] = "hello";    /* ✘ 6字节塞进5格：'\0'被截掉（编译器报错或警告） */

/* 事故2：中途截断却没补\0 */
char buf[16] = "hello world";
buf[5] = '\0';          /* 显式截断 → "hello"，printf %s 只会打印到这里 */
/* 反之：如果把某个字符改成\0，后面的数据还在内存里，只是%s"看不见" */

/* 事故3：char区间装不下扩展ASCII/中文一个字节 */
char c = '中';          /* 多字节字符，c只拿到一个字节（截断） */
```

## 遍历字符串的惯用法

```c
const char *s = "hello";

/* 惯用法1：下标 */
for (size_t i = 0; s[i]; i++)
    putchar(s[i]);

/* 惯用法2：指针走查（更"C味"） */
for (const char *p = s; *p; p++)
    putchar(*p);

/* 惯用法3：*p++ 风格 */
char *p = buf;
while (*p)
    *p++ = toupper(*p);    /* 原地大写化 */
```

## 多字节与宽字符（进阶）

C对非ASCII文本提供两套方案：

```c
/* 1. 多字节字符串（UTF-8）：char数组，一个汉字占3字节 */
char *zh = "你好";          /* strlen(zh) = 6，不是2！ */

/* 2. 宽字符（wchar_t）：一个wchar对应一个码点 */
#include <wchar.h>
wchar_t *w = L"你好";       /* wcslen(w) = 2 */
```

## 命令行参数：main 的字符串数组

```c
int main(int argc, char *argv[])
{
    /* argc = 参数个数(含程序名)；argv = 指针数组，元素是字符串 */
    /* ./prog hello world → argc=3 argv[1]="hello" argv[2]="world" */
    for (int i = 0; i < argc; i++)
        printf("argv[%d] = %s\n", i, argv[i]);
    /* argv[argc] 恒为 NULL（哨兵） */
}
```

`char *argv[]` 就是指针数组的标准实战场景。

## 实战：编译提取汇编逐行解析（真实输出）

> 以下汇编全部为**真实编译产物**，指令逐字来自 gcc 输出，`;` 注释为整理所加。提取流程见 `.opencode/skills/c-dev/SKILL.md`；环境噪音说明见[数组·实战](数组.md)。
> 实测环境：Ubuntu 24.04 / gcc 13.3.0 / x86-64（System V ABI）/ Intel 语法

### 实验1：手写 strcpy —— `(*d++ = *s++)` 的逐指令形态

```c
char *mycpy(char *d, const char *s)
{
    char *r = d;
    while ((*d++ = *s++))      /* 拷贝-前进-判零，一气呵成 */
        ;
    return r;
}
int main(void)
{
    char buf[16];
    mycpy(buf, "hello");
    return buf[0] + buf[4];    /* 'h'+'o' → 实测退出码215 ✔ */
}
```

```asm
mycpy:
    endbr64
    push    rbp
    mov     rbp, rsp
    mov     QWORD PTR -24[rbp], rdi    ; d
    mov     QWORD PTR -32[rbp], rsi    ; s
    mov     rax, QWORD PTR -24[rbp]
    mov     QWORD PTR -8[rbp], rax     ; r = d（留作返回值）
    nop
.L2:                                 ; ── 一轮拷一个字符 ──
    mov     rdx, QWORD PTR -32[rbp]   ; 取s
    lea     rax, 1[rdx]               ; s+1
    mov     QWORD PTR -32[rbp], rax   ; s++（后缀：先算好新值写回）
    mov     rax, QWORD PTR -24[rbp]   ; 取d
    lea     rcx, 1[rax]               ; d+1
    mov     QWORD PTR -24[rbp], rcx   ; d++
    movzx   edx, BYTE PTR [rdx]       ; ★读【旧s】指向的字符（rdx还是老指针）
    mov     BYTE PTR [rax], dl        ; ★写进【旧d】（rax还是老指针）
    movzx   eax, BYTE PTR [rax]       ; 读回刚写的字节
    test    al, al                    ; 是'\0'吗？
    jne     .L2                       ; 不是 → 继续拷
    mov     rax, QWORD PTR -8[rbp]    ; 返回r
    pop     rbp
    ret

main:
    ...
    lea     rax, -32[rbp]             ; buf地址（栈）
    lea     rdx, .LC0[rip]            ; "hello"地址（rodata）
    mov     rsi, rdx
    mov     rdi, rax
    call    mycpy
    ...
```

看清惯用法的物理拆解——**`*d++ = *s++` 一行 = 8条指令**：

1. 两个后缀`++`各自展开为"旧值暂存 + 新值写回"（[运算符·实验1](运算符.md)的"先用后加"在指针上的重演）；
2. 读写字符用的都是**旧指针**（rdx/rax），新指针已先行写回变量；
3. `test al,al; jne` 判 `\0`——**`\0` 也被拷进去**，且拷到它才停（这就是"含结尾符"的机器语义）。

### 实验2：手写 strlen —— 指针走查的优化形态

```c
#include <stddef.h>
size_t mylen(const char *s)
{
    const char *p = s;
    while (*p) p++;
    return (size_t)(p - s);
}
int main(void) { return (int)mylen("hello world"); }  /* 11 → 实测退出码11 ✔ */
```

**-O2**：

```asm
mylen:
    endbr64
    cmp     BYTE PTR [rdi], 0         ; 入口守卫：第一个字符就是'\0'?
    je      .L4                       ;   是 → 长度0
    mov     rax, rdi
.L3:                                 ; ── 指针走查 ──
    add     rax, 1                    ; p++
    cmp     BYTE PTR [rax], 0         ; *p == '\0'?
    jne     .L3
    sub     rax, rdi                  ; ★长度 = p - s（指针差：见[指针·实验2](指针.md)）
    ret
.L4:
    xor     eax, eax
    ret
```

熟悉的配方：入口守卫 + do-while 走查（[循环·反转](控制语句-循环.md)），结尾一条 `sub` 算指针差。**strlen 的 O(n) 就写在 `add rax,1 + cmp + jne` 这三拍一循环里**——每个字节一拍比较，别指望更快（SIMD版是16字节一批，那是 glibc 的事）。

### 汇编视角总结表（全部实测）

| C惯用法 | 机器形态 |
| --- | --- |
| `*d++ = *s++` | 旧指针暂存 + 新指针写回 + 用旧指针读写（8条/轮） |
| `while (*p) p++` | `cmp byte[rax],0; jne` 走查 |
| `p - s`（长度） | `sub rax, rdi` |
| `"hello"` 字面量 | `.rodata` 的 `.LC0`（见[常量区·实战](常量区.md)） |
| `char buf[16]` | 栈上预留 + 金丝雀保护 |

## 小结

1. C字符串 = 字符数组 + `\0` 约定；一切str函数靠 `\0` 判界；
2. `char a[]="x"`（栈，可改）与 `char *p="x"`（rodata，不可改）必须秒判；
3. `sizeof` 编译期含`\0`；`strlen` 运行期不含`\0`；
4. `strcmp` 相等返回**0**；`strncpy` 源长于n时**不补`\0`**——两大经典坑；
5. `(*dst++ = *src++)` 与 `while(*p)` 是C字符串编程的肌肉记忆——实测一行惯用法=8条指令，`++`的"先用后加"语义完全展开在指针上。
