# 优先级

## 完整优先级表（从高到低）

| 优先级 | 运算符 | 名称/含义 | 结合性 | 备注 |
| --- | --- | --- | --- | --- |
| 1 | `()` `[]` `->` `.` | 括号/下标/成员 | 左→右 | `()` 这里指函数调用 |
| 2 | `-` `+` `!` `~` | 单目负/正/逻辑非/按位反 | **右→左** | 一元运算符全家 |
| 2 | `++` `--` | 前缀自增自减 | 右→左 | |
| 2 | `(类型)` | 强制转换 | 右→左 | |
| 2 | `*` `&` | 解引用/取地址 | 右→左 | 此处是单目 |
| 2 | `sizeof` | 求大小 | 右→左 | 运算符非函数 |
| 3 | `*` `/` `%` | 乘除模 | 左→右 | |
| 4 | `+` `-` | 加减 | 左→右 | |
| 5 | `<<` `>>` | 左移/右移 | 左→右 | |
| 6 | `<` `<=` `>` `>=` | 关系（大小） | 左→右 | |
| 7 | `==` `!=` | 关系（相等） | 左→右 | **比大小低** |
| 8 | `&` | 按位与 | 左→右 | |
| 9 | `^` | 按位异或 | 左→右 | |
| 10 | `|` | 按位或 | 左→右 | |
| 11 | `&&` | 逻辑与 | 左→右 | |
| 12 | `||` | 逻辑或 | 左→右 | |
| 13 | `?:` | 条件 | **右→左** | 唯一三目 |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` `&=` `^=` `|=` `<<=` `>>=` | 赋值 | **右→左** | |
| 15 | `,` | 逗号 | 左→右 | 最低 |

## 必须警惕的经典案例

### 1. `==` 低于大小比较

```c
int r = 3 > 2 == 1;
/* 等价 (3 > 2) == 1 → 1 == 1 → 1，碰巧对，但可读性差 */
```

### 2. 位运算低于关系运算符

```c
if (x & 1 == 0)          /* 等价 x & (1 == 0) → x & 0 → 恒为0！BUG */
if ((x & 1) == 0)        /* ✔ 正确写法 */
```

**位运算必须加括号**，这是最高频优先级事故。

### 3. `&&` 高于 `||`

```c
a || b && c      /* 等价 a || (b && c) */
/* 若本意是 (a || b) && c —— 结果完全不同 */
```

### 4. 三目的右结合

```c
a ? b : c ? d : e
/* 等价 a ? b : (c ? d : e) —— 常用于链式判断 */
```

### 5. 单目运算符右结合

```c
*p++       /* 等价 *(p++)：取 p 指向的值，然后 p 前进
              而不是 (*p)++：把 p 指向的值加 1 */
-*p        /* 等价 -( *p ) */
!p++       /* 等价 !( p++ ) */
```

`*p++` 是C语言最惯用的表达式之一（遍历字符串的核心写法）。

### 6. 赋值右结合

```c
a = b = c = 0;    /* a = (b = (c = 0))，从右往左依次赋值 */
```

## 优先级分析方法

遇到复杂表达式，从**优先级最低**的运算符入手切分（它最后算）：

```c
/* 例：分析 x = y + 1, z = 2 的结构 */
/* 最低是逗号 → 拆成两个表达式：
      x = y + 1
      z = 2
   整个逗号表达式的值 = 2 */
```

```c
/* 例：*p.f */
/* '.' 高于 '*' → *(p.f)：p 是结构体，取成员 f 后再解引用
   若 p 是指针想取成员，必须写 p->f 或 (*p).f */
```

## 小结

1. 记不住就加括号，**位运算与`==`混用必须括号**；
2. 单目 > 算术 > 移位 > 关系 > 位 > 逻辑 > 条件 > 赋值 > 逗号；
3. `*p++` = `*(p++)`，惯用法必须秒懂；
4. 结合性只在**同优先级**时起作用：算术左结合，单目/三目/赋值右结合。
