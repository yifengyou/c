# 枚举类型

## 基本用法

枚举把一组**整数常量**起名打包，提高可读性：

```c
enum Color { RED, GREEN, BLUE };      /* 默认从0开始：RED=0, GREEN=1, BLUE=2 */

enum Color c = GREEN;
if (c == GREEN) printf("绿色\n");
```

可指定值：

```c
enum Level {
    DEBUG = 0,
    INFO  = 1,
    WARN  = 30,
    ERROR = 40,       /* 未指定的接着上一个+1 */
    FATAL             /* = 41 */
};

enum { A = 1, B = 2, C = 4, D = 8 };  /* 无名枚举当常量集合用 */
```

## 枚举的本质

**枚举常量就是 int 常量**，枚举变量是能装下这些值的整型变量：

```c
enum Color c = 0;          /* 0 就是 RED，类型宽松（老代码常态） */
enum Color d = 100;        /* 多数编译器不报错！枚举不做范围检查 */
printf("%d\n", GREEN);     /* 1：枚举常量可直接当整数用 */
```

```c
/* 上面代码等价于 —— 编译器眼里的真实形态 */
#define RED   0
#define GREEN 1
#define BLUE  2
int c = 1;
```

## 枚举 vs #define

| 对比 | enum | #define |
| --- | --- | --- |
| 调试器可见？ | ✔ 显示名字（gdb中 `p Color::GREEN`） | ✘ 预处理期消失 |
| 类型关联 | 语义上成组（enum Color） | 散落的魔法数字 |
| 自动编号 | ✔ 依次+1，插入新值不用手改 | ✘ 全手动 |
| 能否用于数组大小/switch | ✔ 常量表达式 | ✔ |
| 能否用于预处理 `#if` | ✘（预处理在编译前） | ✔ |

```c
/* enum 的成组性带来的经典模式： */
enum State { STATE_IDLE, STATE_RUN, STATE_ERR, STATE_MAX };
/* STATE_MAX 作为"哨兵"自动=成员个数 */

const char *names[STATE_MAX] = { "idle", "run", "err" };  /* 表驱动：名字表 */
void handle(enum State s)
{
    if (s >= STATE_MAX) return;      /* 范围检查 */
    printf("%s\n", names[s]);        /* 值→名字（日志友好） */
}
```

## switch + enum：黄金搭档

```c
enum Command { CMD_START, CMD_STOP, CMD_RESET };

void dispatch(enum Command cmd)
{
    switch (cmd) {
    case CMD_START: start();  break;
    case CMD_STOP:  stop();   break;
    case CMD_RESET: reset();  break;
                    /* 不写default：gcc -Wall 会在新增枚举值时警告漏分支！ */
    }
}
```

这是C语言实现**状态机/命令分发**最清晰的方式。

## 位标志枚举（flags 模式）

```c
enum Perm {
    PERM_READ  = 1 << 0,   /* 0001 */
    PERM_WRITE = 1 << 1,   /* 0010 */
    PERM_EXEC  = 1 << 2    /* 0100 */
};

int perm = PERM_READ | PERM_WRITE;              /* 组合：0011 */

if (perm & PERM_WRITE) { }                      /* 测试某位 */
perm |= PERM_EXEC;                              /* 添加 */
perm &= ~PERM_READ;                             /* 移除 */
```

> 类似 Linux 的 `O_RDWR|O_CREAT`、`PROT_READ|PROT_WRITE`，本质都是位标志组合。展开原理见[位运算](位运算.md)。

## 陷阱

```c
/* 1. 重复值 */
enum E { A = 1, B = 1 };       /* 合法！但 switch 两个case会冲突 */

/* 2. 枚举变量赋非枚举值无检查 */
enum Color c = 99;             /* 编译器通常不报错（C比C++宽松得多） */

/* 3. 跨类型比较 */
enum Color c = RED;
int x = 0;
c == x;                        /* 恒成立（都是int语义），但语义上可疑 */
```

## C23 增强速览

```c
enum E : uint8_t { A, B, C };   /* C23：可指定底层类型 */
```

详见[C标准演进](C标准演进.md)。

## 小结

1. 枚举 = 整数常量的成组命名，本质是int，**不做运行时范围检查**；
2. `STATE_MAX` 哨兵 + 名字表是枚举的标准工程模式；
3. `1<<n` 位标志枚举是权限/选项组合的通用解；
4. 配合 switch 且不写 default，让编译器帮你查漏分支。
