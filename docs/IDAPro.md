# IDA Pro 静态调试

> IDA Pro 是逆向界的"标准答案"：把二进制反汇编成交互式数据库，配伪代码（F5）与海量签名识别。静态=不运行程序，先"读"它。简介见 [IDAPro简介](IDAPro/IDAPro简介.md)。

## 为什么先学静态

* 程序不跑，风险为零（对付反调试/恶意样本）；
* 全景视野：一次看全所有函数与调用关系（动态调试是"盲人摸象"）；
* 与本库的配合：你已经会用 `objdump` 手工反汇编（各实战篇），IDA 是它的"超能力版"。

## 静态三板斧（对照 crackme 流程）

| 步骤 | IDA操作 | 手工版（本库已练） |
| --- | --- | --- |
| 找字符串 | `Shift+F12` Strings窗口 → 双击定位 → `X`查交叉引用 | `strings` + `grep` |
| 定位校验函数 | 从字符串引用跳到代码 → 识别 `strcmp/cmp/jcc` | `objdump -d` 肉眼扫 |
| 看懂逻辑 | `F5` 反编译成伪代码（需Hex-Rays） | 手工按[汇编板块](../汇编.md)逐行读 |

## 必会快捷键

| 键 | 功能 | 备注 |
| --- | --- | --- |
| `F5` | 伪代码 | 学过C的你读它零成本 |
| `X` | **交叉引用**（谁用了这个函数/字符串/变量） | 逆向最重要的单个操作 |
| `N` | 重命名 | 给 `sub_401000` 起真名，笔记就位 |
| `Y` | 改类型 | 配合[结构体偏移](../C语言/结构体.md)还原struct |
| `G` | 跳转地址 | —— |
| `Space` | 图形/文本视图切换 | 图形视图直接看跳转结构 |

## 用本库知识读IDA（示例映射）

```text
IDA伪代码                     ←→  你已掌握的底层
if ( !strcmp(v1, "Water") )   ←→  call strcmp; test eax,eax; je
                              ←→  [crackme01·决胜jcc]
v2 = name[i] * (i + 1);       ←→  imul eax, edx（加权）
                              ←→  [crackme02·算法重建]
result ^= 0xDEADBEEFu;        ←→  xor eax, -559038737
                              ←→  [进制·魔数的十进制脸]
```
