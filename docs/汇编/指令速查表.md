## 标志与条件

| 指令/家族 | 语义 | 实测出处 |
| --- | --- | --- |
| `setcc r8` | 按标志置0/1字节（setl/setb/sete/setne） | [类型转换·实验3](../C语言/类型转换.md) |
| ★ `jcc` 家族 | 见下表（jl/jle/jg/jge=带符号；jb/jbe/ja/jae=无符号；je/jne=相等） | [跳转指令集](跳转指令集.md) |
| ★ `jmp` | 无条件跳（含`jmp rax`间接、`jmp [表+idx*8]`查表） | [分支·实验2](../C语言/控制语句-分支和跳转.md) |

**jcc速记**（`less/greater`=带符号，`below/above`=无符号）：

```text
带符号：jl(SF≠OF)  jle(或ZF)  jg(且非ZF)  jge(SF=OF)
无符号：jb(CF)     jbe(CF或ZF) ja(无CF无ZF) jae(无CF)
相等：  je(ZF)     jne(非ZF)
越界防：ja（负数当大数）——switch/数组的单检查防线
```

## 使用方法

1. **逆向时**：objdump/IDA里遇到陌生指令 → 按表反查语义 → 点出处看逐行注解的完整上下文；
2. **学习时**：按[汇编板块目录](汇编.md)顺序过一遍，本表当"错题本"定期回顾；
3. **出题时**：本表就是"看汇编猜C代码"题库的母本。
